# LoadingSkeleton

Pladsholdere, mens data hentes.

**Byg på shadcn/ui:** Skeleton

**Du leverer:** `variant` (list, card, text), `rows`, `label`.

## Regler

- Skeletons har samme mål som indholdet, så skærmen ikke hopper.
- `label` læses op af skærmlæsere ("Henter vagter…").
- Animationen stopper ved `prefers-reduced-motion`.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
