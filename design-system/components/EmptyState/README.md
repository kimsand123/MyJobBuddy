# EmptyState

Tom tilstand med ikon, kort forklaring og én handling.

**Byg på shadcn/ui:** —

**Du leverer:** `icon`, `title`, `text`, `actionLabel`, `onAction`.

## Regler

- Titlen siger, hvad der mangler; teksten siger, hvad brugeren får ud af at tilføje det.
- Én knap, der løser det.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
