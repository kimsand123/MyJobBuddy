# PlanCard

Et abonnement under Mig: Gratis, Plus eller Betal pr. spørgsmål.

**Byg på shadcn/ui:** Card + Progress + Button

**Du leverer:** `name`, `price`, `features`, `current`, `usage` ({used, total, unit}), `ctaLabel`, `onSelect`.

## Regler

- Det nuværende abonnement har `primary`-kant og badgen "Dit abonnement".
- Gratis viser forbruget: "3 af 5 spørgsmål tilbage" og en Progress.
- Priser skrives "29 kr./md."

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
