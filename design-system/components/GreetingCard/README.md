# GreetingCard

Hilsen øverst på Hjem med fornavn, job, arbejdsplads og overenskomst.

**Byg på shadcn/ui:** Card

**Du leverer:** `firstName`, `job`, `workplace`, `agreement`, `loading`.

## Regler

- Kun fornavn: "Hej Maja".
- Overenskomsten vises som `primary`-badge; tryk på "Mig" for at skifte den.
- Loading viser skeletons i samme mål.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet; loading, tom og fejl også, hvor komponenten har dem.
