# EscalationCard

Henvisning til fagforening ved alvorlige sager.

**Byg på shadcn/ui:** Card + Button

**Du leverer:** `text`, `title`, `onShare`, `onLater`.

## Regler

- Vises lige efter et kort, roligt AI-svar.
- Titel: "Det her bør du få hjælp til." Tekst: "Kontakt en fagforening, fx HK Handel."
- HK Handel nævnes kun med tekst, aldrig med logo.
- "Del min sag" åbner ConsentSheet; der sendes intet direkte fra kortet.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
