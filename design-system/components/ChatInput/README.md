# ChatInput

Tekstfelt og send-knap nederst i chatten med antal spørgsmål tilbage.

**Byg på shadcn/ui:** Textarea + Button

**Du leverer:** `value`, `onChange`, `onSend`, `remaining`, `total`, `sending`, `disabled`.

## Regler

- Labelen "Dit spørgsmål" er synlig.
- Send-knappen er deaktiveret, når feltet er tomt.
- "3 af 5 spørgsmål tilbage" står under feltet; ved 0 er feltet deaktiveret med en forklaring.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
