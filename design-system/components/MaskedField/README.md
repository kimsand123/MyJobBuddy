# MaskedField

Viser et skjult personoplysningsfelt som ••••••-•••• med mærket "Skjult for AI".

**Byg på shadcn/ui:** Badge

**Du leverer:** `label`, `maskedValue`, `badgeText`.

## Regler

- Brug til CPR-nummer, kontonummer og adresse efter upload.
- Den rigtige værdi sendes aldrig til AI og vises aldrig i appen.
- Mærket står altid ved siden af værdien.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
