# SuggestedQuestionChips

Forslag til spørgsmål i chatten.

**Byg på shadcn/ui:** Button (outline, rund)

**Du leverer:** `questions`, `onSelect`, `disabled`.

## Regler

- Højst tre forslag ad gangen, skrevet som brugeren ville skrive dem.
- Hver chip er mindst 44px høj og må bryde over flere linjer.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
