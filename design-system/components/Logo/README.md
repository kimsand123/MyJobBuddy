# Logo

App-mærket "Spor" (et j i én tyk streg med en prik over) og navnet "Min Jobbuddy".

**Byg på shadcn/ui:** —

**Du leverer:** `size`, `showName` og `tile` (true: mærket på en `primary` firkant; false: kun J'et).

## Regler

- Med firkant (`tile`): `primary` flade med `radius` 18/64, hvid streg (`primary-foreground`) og prik i `navy-accent`. Brug i AppHeader og som app-ikon.
- Uden firkant: streg i `primary` og prik i `primary-bright` direkte på `background` eller `card`. Brug kun, hvor der er luft omkring mærket.
- Navnet sættes i Figtree 800 til højre for mærket.
- J'et må ikke drejes, strækkes, farves om eller have skygge. Prikken sidder altid over stregen.
- App-ikoner til PWA og butikker ligger under Assets › Logos.
