# ConsentToggle

Samtykke, der kan slås til og fra, med forklaring og synlig "Til"/"Fra".

**Byg på shadcn/ui:** Switch

**Du leverer:** `label`, `description`, `checked`, `onChange`, `disabled`.

## Regler

- Sygdom har sit eget samtykke: "Må vi gemme, når du har været syg? Det bruger vi til at tjekke din løn under sygdom."
- Samtykker er altid "Fra" fra start.
- Status står som tekst ("Til"/"Fra") ved siden af kontakten.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
