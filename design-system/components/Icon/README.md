# Icon

Lucide-linjeikoner, 24px og streg 2; i koden bruges lucide-react med samme navne.

**Byg på shadcn/ui:** lucide-react

**Du leverer:** `name` (Lucide-navn, fx `wallet`), `size`, `label` (kun når ikonet står alene og betyder noget).

## Regler

- Ikoner arver tekstfarven (`currentColor`).
- Ikoner uden tekst får `label` (fx knappen "Tilbage") eller ligger i en knap med `aria-label`.
- Funktionerne: Kontrakt `file-text`, Vagter `calendar-days`, Løn `wallet`, Rettigheder `scale`, AI `sparkles`.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
