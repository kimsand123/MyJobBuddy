# PromoBanner

Det mørkeblå "Spørg AI"-banner på Hjem.

**Byg på shadcn/ui:** Card

**Du leverer:** `title`, `text`, `actionLabel`, `onClick`, `disabled`.

## Regler

- Kun ét banner pr. skærm, og kun på Hjem.
- Teksten kan nævne, hvor mange gratis spørgsmål der er tilbage.
- Når der ikke er flere spørgsmål, er knappen deaktiveret, og teksten forklarer hvorfor.

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
