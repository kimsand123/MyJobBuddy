# Badge

Kort statusmærke med ikon og tekst.

**Byg på shadcn/ui:** Badge

**Du leverer:** `tone` og `children`. Statustoner (success, warning, danger, info) får selv deres ikon; `icon` overskriver.

## Regler

- Farve bærer aldrig betydning alene: der er altid et ikon og et ord.
- success = "I orden", warning = "Mulig fejl", danger = "Fejl", info = "Til info".
- `primary` med `eye-off` er mærket "Skjult for AI".
- `neutral` med `clock` er "Kommer snart".

## Tilstande

Normal, fokus (2px `ring`, 2px afstand) og deaktiveret er vist i previewet.
